## 1. Executive summary

The HIT direction evolved from explicit hardness-induced transport into a broader family of object-aware, residual-based P2 evidence mechanisms.

The main empirical conclusion is:

> **W1 additive independent raw evidence is the strongest clean design tested in this direction.**

Reference:

- W1-add test mAP50: **`0.8031`**
- W1-add + canonical FTAL: `0.7924`
- Clean C1/C2/C3 content experiments: `0.7021 / 0.7683 / 0.7693`
- Multiplicative M1/M2/M3: `0.7672 / 0.7877 / 0.7866`
- Selective S1/S2: `0.7444 / 0.7320`

The old exploratory C2 reached `0.8082`, slightly above W1, but it was not a valid clean hard-negative experiment. Its negative samples were selected from reconstruction hardness rather than detector false positives. The old implementation and artifacts were preserved separately.

No clean follow-up improved W1 on the matched test protocol.

## 2. Problem framing and HIT hypothesis

LEVIR-Ship contains tiny ships against repeated maritime background. The P2 feature map has high spatial resolution but still contains ambiguity from sea texture, wake patterns, reflections, coastline fragments, and weak tiny-object evidence.

The original HIT hypothesis was:

1. A feature that is difficult to reconstruct contains irreducible evidence.
2. Spatial and channel reconstruction failures can be combined into a hardness map.
3. Hard evidence can be selected as a source.
4. The source can be transported toward more useful P2 locations.

The later object-aware redesign separated three concerns:

```text
reconstruction hardness:  how difficult is the feature to reconstruct?
source probability:       is hard evidence object-relevant?
enhancement:              how should selected evidence modify P2?
```

This separation became the basis for H1-H3, W1/W2, M1-M4, S1/S2, and C1-C3.

## 3. Original HIT: Hardness-Induced Transport

### 3.1 Core reconstruction mechanism

The original HIT module used two reconstruction branches:

```text
X -> masked-center spatial reconstruction -> Rs = X - Xsp
X -> compressed channel reconstruction  -> Rc = X - Xch
```

The spatial branch used a masked-center convolution. The channel branch used a 1x1 bottleneck reconstruction path.

The dual hardness map was:

```python
a = Rs.abs().mean(1, keepdim=True)
b = Rc.abs().mean(1, keepdim=True)
H_raw = 2 * a * b / (a + b + eps)
H = (H_raw / H_raw.mean((2, 3), keepdim=True).detach().clamp_min(eps)).clamp(max=5.0)
```

The original concept then selected hard locations, predicted offsets, performed Gaussian transport, and added the transported residual to P2.

### 3.2 Original transport pipeline

```text
P2
 ├─ spatial reconstruction -> Rs
 ├─ channel reconstruction -> Rc
 ├─ hardness map H
 ├─ hard-location selection
 ├─ offset prediction
 ├─ Gaussian splatting / transport
 └─ residual projection -> P2'
```

The original transport cap was approximately four P2 cells, with fixed Gaussian sigma `1.0`.

### 3.3 Early cross-model context

An earlier multi-model evaluation reported the following approximate test results. These values belong to a separate evaluation history and are not directly interchangeable with the later seed-42 W1 matrix.

| Model | Method | AP50 | AP75 | mAP50-95 |
|---|---|---:|---:|---:|
| YOLOv8n | HIT | `0.7955 ± 0.0311` | `0.1073 ± 0.0163` | `0.2968 ± 0.0169` |
| YOLOv8n | DBSS | **`0.8118 ± 0.0368`** | **`0.1305 ± 0.0226`** | **`0.3105 ± 0.0280`** |
| YOLOv5n | HIT | `0.6650 ± 0.0596` | `0.0900 ± 0.0217` | `0.2420 ± 0.0349` |
| YOLOv10n | HIT | `0.7013 ± 0.0501` | `0.1584 ± 0.0213` | `0.2905 ± 0.0349` |

**Conclusion:** the original reconstruction-plus-transport mechanism was technically valid, but its complexity did not produce a reliable advantage over simpler P2 or DBSS alternatives.

## 4. Object-aware HIT redesign

### 4.1 Learned source selector

The redesigned HIT retained hardness as a cue but replaced global top-q source selection with a learned object-aware source selector:

```python
Psrc = sigmoid(source_selector(torch.cat([X, H.detach()], dim=1)))
source = E * H * Psrc
```

The selector was:

```text
Conv2d(c1 + 1, max(c1 // 4, 8), 3, padding=1)
SiLU
Conv2d(max(c1 // 4, 8), 1, 1)
```

The final selector layer was initialized with zero weights and bias `-4.0`, giving an initial source probability of approximately `0.018`.

The output projection was zero-initialized, preserving:

```text
P2' = P2
```

at initialization.

### 4.2 Source targets and auxiliary supervision

P2-resolution source targets were constructed from normalized YOLO boxes.

Soft mode:

```text
inside GT box:                    1.0
near box within source_margin=2:  linear decay
far background:                   0.0
```

Box mode:

```text
inside GT box: 1.0
outside:       0.0
```

The source loss was balanced positive/background BCE:

```text
L_source = 0.5 * mean(BCE on target > 0)
         + 0.5 * mean(BCE on target == 0)
```

Reconstruction auxiliary loss was applied mainly on background:

```text
L_recon = 0.1 * (L_spatial + L_channel)
```

GT was used for auxiliary supervision only. It did not directly mask the forward P2 path.

### 4.3 H1, H2, H3 matrix

| Run | Source target | Enhancement | Transport |
|---|---|---|---|
| H1 | soft object + near-object | direct residual | none |
| H2 | soft object + near-object | Gaussian transport | max 4 P2 cells |
| H3 | bbox-only | Gaussian transport | max 4 P2 cells |

H1 used direct residual enhancement. H2 and H3 used local Gaussian transport with per-GT offset candidates.

### 4.4 H1-H3 results

| Run | Val mAP50 | Test mAP50 | Test AP75 | Test mAP50-95 |
|---|---:|---:|---:|---:|
| H1 | `0.8199` | `0.7870` | `0.1060` | `0.2860` |
| H2 | `0.8199` | `0.7807` | `0.0807` | `0.2713` |
| H3 | **`0.8302`** | **`0.7894`** | **`0.1154`** | **`0.2873`** |
| H1 + FTAL | `0.8059` | `0.7250` | `0.0851` | `0.2570` |

Interpretation:

- H3 was the strongest original object-aware HIT run by AP50, AP75, and mAP50-95.
- H2 was below H1, providing no evidence that Gaussian transport was beneficial.
- H1 + FTAL was below H1 on the matched test result.
- No selector-only `E × Psrc` experiment was run in the H1-H3 matrix.

## 5. W1/W2: independent raw evidence family

The next hypothesis was that the main limitation was not how HIT evidence was routed, but whether it was genuinely independent of semantic P2.

### 5.1 Independent raw evidence formation

W1 added an independently formed raw evidence branch to P2:

```text
raw image -> independent raw encoder -> R
P2' = P2 + projection(R)
```

This preserved the main P2 path and pretrained transfer.

Canonical YAML:

```text
models_related/models_config/yolov8/levir/yolov8n_p2_levir_oaief_w1.yaml
```

The module was `ObjectAwareIndependentFusion`.

### 5.2 W1-add

W1 used additive independent evidence:

```text
X' = X + Delta(R)
```

The output projection was identity-safe / zero-initialized. W1 remained the strongest clean HIT-derived design.

### 5.3 W2 detached Psrc routing

W2 tested detached source-probability routing:

```text
X' = X + Delta(R) * detach(Psrc)
```

The goal was to use object-aware routing without allowing the detector branch to directly hack the routing mechanism.

### 5.4 W1/W2 results

| Run | Val mAP50 | Test mAP50 |
|---|---:|---:|
| W1-add | `0.8187` | **`0.8031`** |
| W2 detached Psrc | `0.8217` | `0.7720` |
| W1 + canonical FTAL | `0.8252` | `0.7924` |

FTAL did not improve W1 under the matched test protocol.

## 6. Multiplicative modulation family

The multiplicative family tested whether raw evidence should modulate P2 instead of being added as an independent residual.

### M1: element-wise modulation

```text
X' = X * (1 + alpha * tanh(G(R)))
```

### M2: spatial modulation

A spatial modulation map was used to modulate all P2 channels at each location.

### M3: channel modulation

A channel-oriented modulation path was used to learn channel-level evidence scaling.

### M4: global plus object-conditioned correction

M4 combined a global correction with object-conditioned correction.

### Results

| Run | Val mAP50 | Test mAP50 |
|---|---:|---:|
| M1 element-wise | `0.8051` | `0.7672` |
| M2 spatial | `0.8232` | `0.7877` |
| M3 channel | **`0.8472`** | `0.7866` |
| M4 global/object | `0.7602` | `0.6992` |

M3 had the strongest validation score in this family, but none exceeded W1 on the matched test split. M4 was clearly negative.

**Decision:** close multiplicative modulation as a primary direction.

## 7. Selective residual family

The selective residual family tested identity-centered gates around W1 additive evidence.

### S1: spatial gate

```text
X' = X + G_spatial(X, R) * Delta(R)
```

### S2: element-wise gate

```text
X' = X + G_elementwise(X, R) * Delta(R)
```

Both gates were centered at one and initialized to preserve identity behavior.

| Run | Val mAP50 | Test mAP50 |
|---|---:|---:|
| S1 spatial | `0.8202` | `0.7444` |
| S2 element-wise | `0.8037` | `0.7320` |

Both were substantially below W1.

**Decision:** do not tune selection/modulation further without a new hypothesis.

## 8. Complementary evidence-content family

The complementary family tested whether the independent evidence content itself could be improved.

### C1: predictability-filtered evidence

Hypothesis: remove the part of raw evidence predictable from semantic P2.

```python
predicted = predictor(detach(X))
content = R - detach(predicted)
X' = X + projection(content)
```

The corrected clean version retained W1 source selector and source BCE so that the comparison was matched.

### C2: detector-confidence hard negatives

The intended premise was:

```text
positive:       actual P2/TAL assigned object candidates
hard negative:  high-confidence detector candidates not assigned to GT
```

The corrected C2 exposed P2 detector confidence and TAL foreground context to the auxiliary loss. High-confidence unmatched P2 locations were selected as hard negatives.

The earlier exploratory C2 was not equivalent. It selected top reconstruction-hardness background locations:

```text
hard negative = background locations with high HIT reconstruction hardness
```

That earlier experiment remains useful as an exploratory result but must not be interpreted as detector false-positive supervision.

### C3: cross-representation retrieval

C3 used semantic P2 queries against compressed raw evidence keys and values:

```text
Q = query(X)
K,V = compressed key/value(R)
retrieved = softmax(QK^T / sqrt(d)) V
X' = X + retrieve_out(retrieved)
```

The output path was zero-initialized for identity behavior. The corrected version retained W1 source auxiliary supervision and removed the unused/dead evidence projection.

### Exploratory results

| Run | Val mAP50 | Test mAP50 | Premise status |
|---|---:|---:|---|
| Exploratory C1 | `0.8163` | `0.7766` | Missing W1 source auxiliary |
| Exploratory C2 | `0.8348` | **`0.8082`** | Reconstruction-hard negatives, not detector FPs |
| Exploratory C3 | `0.7716` | `0.7340` | Missing W1 source auxiliary |

### Corrected clean results

|---|---:|---:|

## 13. Final scientific conclusions

1. **Independent raw evidence is more promising than direct HIT transport.** W1-add is the strongest clean result.
2. **Routing, modulation, and selective gating are not currently justified.** They all underperform W1 on the matched test split.
3. **FTAL did not improve the tested W1 or C2 representations.** This is a result for these exact combinations, not a universal claim that FTAL is harmful.
4. **The old exploratory C2 result must remain labeled exploratory.** Its `0.8082` test mAP50 is interesting, but the hard negatives were reconstruction-hardness locations rather than detector false positives.
5. **Clean C1/C2/C3 did not validate the complementary-evidence hypotheses.** The clean test results remain below W1.
6. **The main unresolved design principle is independent representation formation.** A useful second representation should be formed independently, preferably from near-raw input, before fusion. This principle is retained, but the tested C1-C3 implementations did not produce a win.
7. **Do not add more HIT transport, modulation, gating, or FTAL tuning without a new hypothesis.** The current evidence supports stopping the existing HIT/OAIEF matrix at W1-add as the reference design.

---

## 14. Recommended next step

Use W1-add as the control/reference for any future work. If continuing the HIT direction, change only one premise at a time and require:

```text
matched W1 auxiliary supervision
same seed and schedule
same P2 path and pretrained transfer
explicit test mAP50 gate
remote artifact verification
```

The next new experiment should focus on the **content and formation of an actually independent representation**, not another selector, gate, transport, or global attention variant.
