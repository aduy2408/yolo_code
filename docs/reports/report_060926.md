## 1. Objective

This session replaced the old HIT source-selection mechanism and tested whether an object-aware feature enhancement can improve P2 detection. The old design allowed global hardness top-q selection to decide which residuals became sources. The new design separates:

```text
reconstruction hardness:      how difficult is this feature to reconstruct?
source probability:           is this hard evidence object-relevant?
enhancement:                  how should selected evidence modify P2?
```

The planned HIT matrix was limited to three runs:

| Run | Source supervision | Enhancement | Offset |
|---|---|---|---|
| H1 | soft object + near-object | direct residual | none |
| H2 | soft object + near-object | Gaussian transport | max 4 P2 cells |
| H3 | bbox-only | Gaussian transport | max 4 P2 cells |

A later follow-up tested **H1 + canonical FTAL** without GAP. No selector-only `E × Psrc` run was performed in this session.

## 2. HIT implementation

### 2.1 Reconstruction branches

`DualIrreducibilityHIT` keeps the two reconstruction branches:

```text
X -> masked-center spatial reconstruction -> Rs = X - Xsp
X -> compressed channel reconstruction  -> Rc = X - Xch
```

The spatial branch uses `_MaskedCenterConv2d`, whose center kernel weight is masked. The channel branch uses a 1x1 bottleneck with hidden width `max(c1 // reduction, 1)`.

### 2.2 Dual hardness

The hardness map remains the harmonic combination of spatial and channel residual magnitudes:

```python
a = Rs.abs().mean(1, keepdim=True)
b = Rc.abs().mean(1, keepdim=True)
H_raw = 2 * a * b / (a + b + eps)
```

It is normalized per image using detached spatial mean and clipped at `hard_clip=5.0`:

```python
H = (H_raw / H_raw.mean((2, 3), keepdim=True).detach().clamp_min(eps)).clamp(max=5.0)
```

Hardness is only a selector cue and source amplitude signal in this version. There is no global hardness top-k or top-q source selection.

### 2.3 Learned source selector

The selector receives the feature and detached hardness:

```python
Psrc = sigmoid(source_selector(torch.cat([X, H.detach()], dim=1)))
```

The selector is:

```python
Conv2d(c1 + 1, max(c1 // 4, 8), 3, padding=1)
SiLU
Conv2d(max(c1 // 4, 8), 1, 1)
```

The final selector layer is initialized with zero weights and bias `-4.0`, giving an initial probability of approximately `0.018`. This preserves conservative identity behavior at startup.

The evidence path is:

```text
E       = residual_fuse([Rs, Rc])
source  = E × H × Psrc
P2'     = P2 + output_projection(source)
```

The output projection is zero-initialized, so both direct and transport modes initially satisfy `P2' = P2`.

### 2.4 Source targets

The auxiliary target is generated at P2 resolution from normalized YOLO boxes using cell centers `(x+0.5, y+0.5)`.

Soft mode:

```text
inside bbox:                         1.0
within source_margin=2 P2 cells:     linear decay to 0
far background:                      0.0
```

Box mode:

```text
inside bbox:                         1.0
everything outside:                  0.0
```

Multiple boxes are merged with elementwise maximum. GT is used only in auxiliary source and offset supervision. It never masks or scales the forward feature path.

### 2.5 Balanced selector loss

The selector uses elementwise BCE-with-logits, split into positive-support and background means:

```text
L_source = 0.5 * mean(BCE on target > 0)
          + 0.5 * mean(BCE on target == 0)
```

The initial weight is `loss_source_weight=0.5`. Reconstruction uses background-only supervision with `loss_recon_weight=0.1` for each branch.

### 2.6 Direct and transport modes

H1 uses explicit direct enhancement:

```text
source -> output_projection -> residual addition
```

It is not implemented as the old `transport_enabled=False` no-op path.

H2 and H3 use local transport:

```text
offset_input = [detach(X), detach(H), detach(Psrc)]
offsets      = tanh(offset_head(offset_input)) * 4.0
transported  = gaussian_splat(source, offsets)
P2'          = X + output_projection(transported)
```

The transport cap is `4` P2 cells, approximately `16` input pixels at stride 4, with fixed Gaussian sigma `1.0`.

Offset candidates are now generated from the support of **each individual GT box** (per-GT support), not from the union target map for the entire image. If two GTs select the same P2 cell, the assignment keeps the target belonging to the closer GT center.

## 3. H1 + FTAL follow-up

The follow-up run kept the H1 architecture unchanged:

```text
P2 -> object-aware HIT direct enhancement -> P2 Detect
```

No GAP block and no transport were added. The only training change was canonical Factorized TAL:

```yaml
factorized_tal_target: true
factorized_tal_mode: legacy
factorized_tal_tau: 0.75
factorized_tal_kappa: 1.5
factorized_tal_lambda: 0.5
factorized_tal_s_max: 32.0
factorized_tal_warmup_start: 5
factorized_tal_warmup_end: 15
factorized_tal_p2_only: true
```

Here `legacy` is the current canonical FTAL mode name used by the repository to reproduce the historical FTAL behavior. It is not a second FTAL implementation or an additional experiment variant.

## 6. Interpretation

On the uploaded test artifacts:

1. H3 is the strongest of the three original HIT runs by AP50, AP75, and mAP50-95, but the differences from H1 are small.
2. H2 is below H1 on all reported test detection metrics. The current evidence does not support Gaussian transport as an improvement over direct enhancement.
3. H3 slightly exceeds H1, suggesting that near-object soft support may add noise, although this is a single seed and the margin is small.
4. H1 + FTAL is below H1 on the uploaded test metrics. Therefore this run does not support the hypothesis that canonical FTAL converts the H1 representation into better ranking performance under this exact protocol.
5. The FTAL result is not evidence that FTAL is generally harmful. It is specifically a negative result for the H1 + canonical FTAL combination in this run.
6. No conclusion about selector-only weighting `E × Psrc` can be made because that experiment was not run.

## 10. Current conclusion

The object-aware selector was successfully implemented and the three original HIT runs completed with verified artifacts. The current results do not justify adding another transport or GAP ablation. The direct H1 path is the cleaner HIT representation, but H1 + canonical FTAL did not improve the matched test result in this session. The selector-only modification `E × Psrc` remains the most logically targeted follow-up if the direction is revisited, but it was intentionally not included in this report's run matrix.
