# Báo cáo thực nghiệm ngày 25/08/2026: Reproduction FTAL lịch sử và Top-hat

## 1. Mục tiêu

Báo cáo này ghi lại việc xác định và sửa một semantic drift trong Factorized TAL (FTAL), sau đó chạy lại đúng hai ablation cần thiết:

1. `Top-hat + plain FTAL legacy`.
2. `Top-hat + GAP + FTAL legacy`.

Mục tiêu trước đó là kiểm tra tương tác giữa input cue top-hat, GAP và FTAL. Các kết quả top-hat chạy với FTAL `current` trước đây không được dùng để kết luận interaction với historical winner, vì chúng không dùng cùng semantics FTAL.

## 2. Protocol chung

- Dataset: LEVIR-Ship fixed split, split seed `42`.
- Input: RGB normalized, cue được tính bên trong model sau augmentation.
- Architecture: YOLOv8n-P2, chỉ thay đổi stem/cấu hình attention được nêu trong từng variant.
- Image size: `512`.
- Batch size: `8`.
- Epochs: `100`.
- Early stopping: tắt, `patience=0`.
- Training seed: `42`.
- NMS IoU: explicit `0.5`.
- Checkpoint báo cáo: `best.pt`.
- FTAL: `tau=0.75`, `kappa=1.5`, `lambda=0.5`, `s_max=32`, warmup `5 -> 15`, P2-only.

### 3.1. Định nghĩa cụ thể từng cue

Tất cả cue bắt đầu từ grayscale:

```python
y = 0.299*R + 0.587*G + 0.114*B
```

Cue được tính deterministic trong `InputCueBank` với `torch.no_grad()`, ở full resolution, rồi concatenate với RGB trước convolution đầu tiên. Số kênh và phép biến đổi thực tế:

| Cue | Kênh | Implementation cụ thể |
|---|---:|---|
| `sobel_xy` | 2 | Sobel `Gx`, `Gy`, kernel chuẩn hóa `/4`, clamp `[-1, 1]`. |
| `laplacian_split` | 2 | Laplacian 4-neighbor; tách `ReLU(L)` và `ReLU(-L)`. |
| `log` | 1 | Gaussian blur `5x5`, sau đó Laplacian 4-neighbor, clamp `[-1, 1]`. |
| `haar` | 3 | Ba basis Haar 2D `LH/HL/HH`, hệ số `1/2`, padding reflect. |
| `lab_ab` | 2 | RGB tuyến tính sang CIE Lab; dùng hai kênh chromatic `a*` và `b*`, scale về `[-1, 1]`. |
| `ycbcr_cbcr` | 2 | Chuyển đổi tuyến tính sang `Cb` và `Cr`, scale `2`, clamp `[-1, 1]`. |
| `chromatic_edge` | 2 | Sobel magnitude trên `R-G` và `B-(R+G)/2`. |
| `local_zscore` | 1 | Z-score grayscale so với mean/variance local `7x7`, clamp về `[-1, 1]`. |
| `structure_coherence` | 1 | Structure tensor từ Sobel `Gx/Gy`, đo coherence local `5x5`. |
| `top_hat` | 1 | White top-hat `y - opening(y, 5)`, với opening = erosion rồi dilation. |
| `robust_ring_contrast` | 2 | Median center `3x3` so với median ring radius `4`, chuẩn hóa bằng `1.4826*MAD`; tách bright/dark. |
| `lbp_stats` | 2 | So sánh 8 neighbors với center; trả fraction của bit 1 và circular transition rate. |
| `multiscale_tophat` | 2 | Max white/black top-hat qua kernel sizes `5, 11, 21`. |
| `local_rank` | 1 | Tỷ lệ 24 neighbors trong cửa sổ `5x5` có intensity nhỏ hơn center. |
| `phase_coherence` | 1 | Gabor quadrature bank với 2 wavelengths `3, 5` và 4 orientations; max phase agreement qua scale/orientation. |

Các cue không có trainable parameters. Chỉ stem convolution được mở rộng để nhận thêm số kênh trên; trọng số RGB pretrained được copy nguyên trạng và các kênh cue được zero-initialize.

## 4. Phát hiện semantic drift trong FTAL

### 4.1. Historical implementation

Historical winner được train tại commit `a68b00e`. Với mỗi nhóm positive của một GT, code dùng chính TAL target score `q`:

```python
q = target_scores[b, group]
u_max = q.max().clamp_min(1e-12)
q_new = (
    u_max.pow(tau)
    * (q / u_max).clamp(0, 1).pow(kappa)
)
q_final = q + lam * (q_new - q)
```

`target_scores` được tạo từ TAL overlap dùng CIoU. Vì vậy ceiling lịch sử là `q.max()` của TAL target score, không phải một IoU được recompute riêng.

### 4.2. Current refactored implementation

Sau commit `28ac7cc`, implementation được refactor thành:

```python
q_score = q.sum(-1)
q_max = q_score.max()
u_max = u.max()
r = q_score / q_max
q_new_score = u_max.pow(tau) * r.pow(kappa)
```

Trong đó `u` được recompute bằng plain IoU (`CIoU=False`). Đây là một objective khác:

```text
historical: q_max^tau * (q / q_max)^kappa
current:    max(IoU)^tau * (q_score / q_max)^kappa
```

Do đó các run không set `factorized_tal_mode` sau refactor mặc định dùng `current` và không thể so sánh trực tiếp với historical winner.

### 4.3. Cách sửa

Đã thêm mode explicit:

```yaml
factorized_tal_mode: legacy
```

Mode này copy đúng historical semantics, dùng `q.max()` và không dùng recomputed IoU ceiling. Mode `current`, `mass_preserve`, `geometry` và `agreement_gate` vẫn giữ nguyên để không làm thay đổi các experiment target-mode khác.
